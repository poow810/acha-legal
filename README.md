# A-CHA — 공개 법적 고지 페이지

앱스토어·구글플레이 등록에 필요한 공개 URL을 GitHub Pages로 서빙한다.
앱 저장소(비공개)의 `docs/` 내용을 여기로 배포한다.

| 페이지 | 경로 | 용도 |
|---|---|---|
| 개인정보처리방침 | `/privacy/` | 양 스토어 필수 |
| 서비스 약관 | `/terms/` | 스토어 등록정보 |
| 계정 삭제 안내 | `/delete-account/` | Google Play 필수(웹 접근 삭제 경로) |

⚠️ 이 저장소는 **공개**여야 GitHub Pages가 동작한다. 앱 소스는 넣지 말 것.
